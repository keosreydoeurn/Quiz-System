A front-end **Quiz System Web Application** built with HTML, CSS, JavaScript, and Firebase.  
The system supports authentication, multiple quiz categories (HTML, CSS, JavaScript), quiz creation, review, and result tracking.

---

## 📖 Overview

This project allows users to:
- Authenticate using Firebase
- Take quizzes on **HTML, CSS, and JavaScript
- View quiz results
- Review answers
- Create quizzes (admin/user)
- Manage user profiles
- Access help and leaderboard pages

All logic runs on the client side with Firebase handling authentication and data storage.

## ▶️ How to Run

1. Clone or download the project
2. Configure Firebase in `js/firebase.js`
3. Open `index.html` in a modern browser
4. Log in and start the quiz
